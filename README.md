
# 👋 Hey, I'm Diviyan!

### Full Stack Developer | Backend Engineering | Cloud & AI

I'm a Full Stack Developer with a background in Game Development, interested in building applications that solve real-world problems.

My development journey started with creating interactive experiences using Unreal Engine, Unity, and Godot. Over time, I expanded into web and mobile development, working with modern frontend technologies, backend services, databases, and cloud infrastructure.

Currently, I work with React, React Native, TypeScript, Python, Flask, PostgreSQL, and AWS to build and maintain web and mobile applications.

I'm also exploring AI-assisted software development and practical ways to integrate AI into everyday applications and development workflows.
